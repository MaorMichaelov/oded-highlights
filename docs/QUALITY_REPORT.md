## 5. How to read this

- 'cuts through a sentence' = the cut point lies more than 0.3 s (0.6 s for rounded data) inside a Whisper segment; Whisper segments are sentence-like, so this is the objective proxy for 'starts/ends mid-sentence'.
- Title truth is a heuristic: content words are matched by stem, names/numbers fuzzy (difflib >= 0.8); paraphrases of the LLM ('struggles', 'frustration') count as unsupported words, so only names, numbers and quotes block a draft (`cutqa.grade`).
- Media numbers: dead air = time before/after the first/last sound more than 12 dB over the clip's noise floor; abrupt end = last 200 ms still loud; LUFS targets: Shorts -14 +-2, long -16 +-5 (no loudnorm is applied to long videos).
